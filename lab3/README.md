# 🧮 Линейные алгоритмы на Java

> Лабораторная работа по дисциплине «Программирование»

---

## 📌 Цель работы
Изучить принципы построения линейных алгоритмов на языке программирования **Java**,  
освоить применение арифметических операций, оператора присваивания,  
а также ввод и вывод данных с помощью класса `Scanner`.

---

## 📝 Задачи работы
В рамках лабораторной работы были реализованы программы для:

- демонстрации последовательности выполнения команд;
- выполнения основных арифметических операций;
- работы с оператором присваивания;
- организации ввода и вывода данных;
- вычислений по математическим формулам;
- реализации линейных алгоритмов без использования условий и циклов.

---

## 📁 Структура проекта

```text
src/

    └─ java/
       └─ linear/

          ├─ ArithmeticOperations.java
          ├─ AssignmentOperator.java
          ├─ SquareCalculator.java
          ├─ RectangleArea.java

          ├─ RectangleAreaPerimeter.java
          ├─ CircleArea.java
          ├─ CelsiusToFahrenheit.java
          ├─ UniformMotion.java
          └─ SquareAndCube.java
Все классы находятся в пакете linear

Каждый файл содержит один класс и один метод main

Все алгоритмы являются линейными

📄 Описание программ
🔹 ExecutionOrder
Демонстрация последовательности выполнения команд.
Объявляются три целочисленные переменные, выполняется их сложение
и вывод результата в консоль.

🔹 ArithmeticOperations
Программа выполняет операции:

сложение

умножение

деление

Демонстрируется приоритет арифметических операций и работа с типами данных.

🔹 AssignmentOperator
Показано использование оператора присваивания
с арифметическим выражением и изменение значения переменной.

🔹 SquareCalculator
Реализован ввод целого числа с клавиатуры
и вычисление его квадрата с использованием класса Scanner.

🔹 RectangleArea
Вычисление площади прямоугольника
по введённым длине и ширине.

🔹 SumAndAverage
Программа вычисляет сумму
и среднее арифметическое двух введённых чисел.

🔹 RectangleAreaPerimeter
Вычисление площади и периметра прямоугольника
в рамках одного линейного алгоритма.

🔹 CircleArea
Вычисление площади круга по формуле:

ini
Copy code
S = π · r²
где π = 3,14.

🔹 CelsiusToFahrenheit
Перевод температуры из градусов Цельсия
в градусы Фаренгейта по формуле:

ini
Copy code
F = C · 9 / 5 + 32
🔹 UniformMotion
Вычисление расстояния при равномерном движении
по формуле:

ini
Copy code
S = v · t
🔹 SquareAndCube
Вычисление квадрата и куба числа
с повторным использованием переменной.
