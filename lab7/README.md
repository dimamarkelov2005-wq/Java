Теоретические сведения

В программировании массив — это совокупность однотипных переменных, хранящихся в смежных ячейках памяти.

В Java массивы — это ссылочный тип данных. Работа с массивами выполняется в три этапа:

Объявление (declaration)

double[] a, b;

Создание (allocation)

a = new double[5];
b = new double[100];

Инициализация (initialization)

a[0] = 0.01;
a[1] = -3.4;
a[2] = 2.89;
a[3] = 4.5;
a[4] = -6.7;

Многомерные массивы в Java создаются как массивы массивов:

double matrix[][] = new double[4][4];
matrix[0] = new double[4];
matrix[1] = new double[4];
// ...
