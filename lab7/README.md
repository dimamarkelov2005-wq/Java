### 📚 Теоретические сведения

Массив — это набор однотипных элементов, хранящихся в смежных ячейках памяти. В Java массивы — ссылочный тип данных.

Работа с массивами состоит из 3 этапов:

1. **Объявление массива**

```java
double[] a, b;
a = new double[5];
b = new double[100];
a[0] = 0.01;
a[1] = -3.4;
a[2] = 2.89;
a[3] = 4.5;
a[4] = -6.7;
Многомерные массивы — это массивы массивов:

double[][] matrix = new double[4][4];
| №  | Описание задания                                           |
