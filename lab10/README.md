Лабораторная работа 10: Java-апплеты и графический интерфейс

Описание

Этот проект демонстрирует использование Swing для создания графических интерфейсов в Java. В нем представлены решения для 10 задач, каждая из которых реализует отдельный элемент интерфейса или функциональность, как, например, рисование фигур, обработка событий с кнопками, полями ввода, анимацией и т. д.

Проект выполнен с использованием JTabbedPane, который позволяет организовать интерфейс в виде вкладок, каждая из которых соответствует отдельной задаче.

Задачи:
1. Фигуры (Task1_Figures.java)

Рисование простых графических фигур:

Прямоугольник
Круг
Линия
2. Кнопка (Task2_Button.java)

Кнопка, при нажатии на которую выводится текст "Hello Java".

3. TextField (Task3_TextField.java)

Текстовое поле для ввода имени, и кнопка, которая выводит сообщение "Привет, [имя]" после ввода.

4. Смена цвета (Task4_ColorChange.java)

Кнопка для смены цвета фигуры. Фигура меняет свой цвет по циклу: Красный → Зеленый → Синий → Красный.

5. Координаты (Task5_Coordinates.java)

Ввод координат для отображения круга в указанной позиции на экране.

6. Мышь (Task6_Mouse.java)

Отображение координат точки, в которой был произведен клик мышью, а также рисование точки в этой позиции.

7. Клавиатура (Task7_Key.java)

Отображение символа, который был введен с клавиатуры.

8. Калькулятор (Task8_Calculator.java)

Простой калькулятор для сложения двух чисел, введенных в текстовые поля.

9. Анимация (Task9_Animation.java)

Анимация, где круг движется по экрану, возвращаясь в начало после достижения правой границы окна.

10. Checkbox (Task10_Checkbox.java)

Использование чекбоксов для выбора цвета фигуры. Возможные цвета: Красный, Зеленый, Синий.

Структура проекта

Проект состоит из 11 файлов:

Task1_Figures.java — рисование фигур.
Task2_Button.java — кнопка для вывода текста.
Task3_TextField.java — поле ввода имени.
Task4_ColorChange.java — кнопка для изменения цвета.
Task5_Coordinates.java — отображение круга на основе координат.
Task6_Mouse.java — обработка события клика мыши.
Task7_Key.java — обработка клавиатурных событий.
Task8_Calculator.java — калькулятор.
Task9_Animation.java — анимация движения круга.
Task10_Checkbox.java — выбор цвета с помощью чекбоксов.
Main.java — основной класс, который запускает все задачи в виде вкладок.

Как запустить
Клонируйте репозиторий или скачайте проект.
Откройте проект в вашей IDE (например, IntelliJ IDEA).
Запустите файл Main.java, который откроет окно с вкладками, где каждая вкладка будет соответствовать одной из задач.

Используемые технологии:
Java Swing: для создания графического интерфейса.
Java 8+: для работы с графикой, обработкой событий и анимацией.

Примечания
В коде используется JTabbedPane для организации задач в виде вкладок.
Каждая задача реализована в виде отдельного класса, что позволяет легко тестировать и модифицировать каждый элемент интерфейса.
Все задачи являются самодостаточными и могут быть изменены или расширены для других целей.
