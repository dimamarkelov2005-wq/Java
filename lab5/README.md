📖 Теоретические сведения

Цикл — это конструкция, позволяющая выполнять блок кода многократно.

В языке Java используются три основных типа циклов:

Тип цикла	Описание
for	Используется, когда известно количество повторений
while	Проверяет условие перед выполнением тела цикла
do–while	Выполняет тело цикла минимум один раз
continue	Пропускает текущую итерацию
break	Прерывает выполнение цикла
