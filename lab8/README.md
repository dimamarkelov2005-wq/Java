# Теоретические сведения

Графический интерфейс пользователя (GUI) позволяет взаимодействовать с программой через окна, кнопки и графические элементы.

В Java для создания GUI используются библиотеки:

* **AWT (Abstract Window Toolkit)**
* **Swing**

В данной лабораторной работе используется класс **JFrame**, который создаёт окно приложения.

Для рисования графиков используется класс **Graphics**.
Метод **paint(Graphics g)** позволяет рисовать линии, сетку координат и графики функций.

Основные методы:

* `drawLine()` — рисование линии
* `setColor()` — установка цвета
* `Math.sin()` — вычисление синуса
* `Math.cos()` — вычисление косинуса
* `Math.pow()` — возведение в степень

График функции строится путём последовательного вычисления значений **y** для различных значений **x**.

# Принцип работы программы

Программа создаёт графическое окно с помощью класса **JFrame**.

В методе **paint(Graphics g)** выполняются следующие действия:

1. Рисуются оси координат
2. Выполняется цикл по значениям **x**
3. Для каждого **x** вычисляется значение функции **y**
4. Результаты соединяются линиями, образуя график функции

Пример вычисления значения функции:

```
double y = 80 * Math.sin(Math.PI * x / 180);
```

Значение **y** вычисляется как число типа **double**, после чего преобразуется в **int** для отображения на экране.
