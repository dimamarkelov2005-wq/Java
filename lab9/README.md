## 📚 Теоретическая часть

**Наследование** — это механизм объектно-ориентированного программирования, позволяющий одному классу (дочернему) наследовать свойства и методы другого класса (родительского).

### Основные понятия:

* **Базовый класс (superclass)** — родительский класс
* **Производный класс (subclass)** — наследник
* **extends** — ключевое слово для наследования
* **@Override** — переопределение метода

### Преимущества:

* уменьшение дублирования кода
* логическая структура программы
* удобство расширения
