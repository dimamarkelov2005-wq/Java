## 📌 Описание заданий

### 1. Вычисление площади прямоугольника
Метод `rectangleArea(double width, double height)`:
- принимает два параметра типа double;
- возвращает площадь прямоугольника.

---

### 2. Проверка чётности числа
Метод `isEven(int number)`:
- возвращает true, если число чётное;
- возвращает false, если число нечётное.

---

### 3. Перегрузка метода max
Реализованы два метода:
- `max(int a, int b)`
- `max(double a, double b)`

Методы возвращают большее из двух чисел.

---

### 4. Рекурсивный факториал
Метод `factorial(int n)`:
- использует рекурсию;
- содержит базовый случай (n == 0 || n == 1);
- обрабатывает отрицательные значения.

---

### 5. Рекурсивное возведение в степень
Метод `power(int base, int exponent)`:
- использует рекурсию;
- содержит базовый случай (exponent == 0);
- работает для положительных степеней.

---
