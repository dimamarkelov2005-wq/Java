📘 Java Basic Tasks — Работа с циклами и условиями
📌 Описание проекта

Данный репозиторий содержит решения базовых задач по программированию на Java.
Основная цель работы — закрепить навыки использования:

циклов (for, while, do-while)

условных операторов (if-else)

оператора множественного выбора (switch)

работы с пользовательским вводом (Scanner)

арифметических операций

Проект предназначен для учебной практики.
